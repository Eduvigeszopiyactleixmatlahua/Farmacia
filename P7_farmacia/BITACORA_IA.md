## Descripción del acompañamiento académico con IA

Durante el desarrollo del proyecto P7_farmacia, se compartieron con ChatGPT diferentes versiones del código fuente mediante archivos ZIP, así como los requisitos proporcionados por el profesor.

Se solicitó que la inteligencia artificial desempeñara el papel de **profesor particular de programación Java**, analizando el proyecto y proporcionando orientación progresiva para completar las implementaciones.

La metodología de trabajo consistió en compartir el código, identificar los métodos pendientes, recibir explicaciones sobre los conceptos de programación involucrados, implementar las funcionalidades y comprobar los resultados mediante pruebas. Cuando se presentaban errores, se consultaba nuevamente a la IA para comprender su causa y estudiar las posibles correcciones.

Este acompañamiento permitió reforzar los conocimientos de programación orientada a objetos, estructuras de datos, persistencia, manejo de excepciones, interfaces gráficas y documentación de software.

## Conclusión

Para concluir la inteligencia artificial se utilizó como herramienta de apoyo académico y técnico durante las diferentes etapas de desarrollo del proyecto P7_farmacia.

Su principal contribución fue proporcionar explicaciones personalizadas, revisar el código compartido, orientar las implementaciones, resolver dudas, identificar posibles errores y ayudar a organizar las actividades pendientes.
Las recomendaciones proporcionadas por ChatGPT fueron revisadas y, cuando fue necesario, modificadas para adaptarlas a los requisitos y a la estructura del proyecto.
El uso de IA complementó el proceso de aprendizaje, manteniendo la responsabilidad de revisar, comprender, probar y validar las implementaciones incorporadas al sistema.
